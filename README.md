ONG Esperança

1. Sobre o projeto

O projeto ONG Esperança consiste no desenvolvimento de um site para apresentar a organização, divulgar seus projetos sociais e facilitar o acesso às informações sobre cadastro e formas de participação. Foi desenvolvido como atividade prática da disciplina de Desenvolvimento Front-end do curso de Análise e Desenvolvimento de Sistemas (ADS).

2. Funcionalidades

- Apresentação da ONG.
- Página com informações sobre projetos sociais.
- Formulário de cadastro de usuários.
- Navegação entre as páginas do site.
- Melhorias de acessibilidade na navegação e nas mensagens do cadastro.

3. Tecnologias utilizadas

- HTML5: estruturação e organização do conteúdo das páginas.
- CSS3: estilização, cores, layout e adaptação visual.
- JavaScript: implementação de funcionalidades e interações.
- Git: controle de versão e registro das alterações.
- GitHub: hospedagem do repositório e organização do trabalho por meio de branches, Issues, Milestones e Pull Requests.

4. Pré-requisitos

Para visualizar e testar o projeto localmente, é necessário ter:

- Um navegador atualizado, como Google Chrome, Microsoft Edge ou Firefox.
- Os arquivos do projeto disponíveis no computador.
- Um editor de código, como PyCharm ou Visual Studio Code, para consultar ou modificar os arquivos.

Como o projeto utiliza HTML, CSS e JavaScript diretamente no navegador, não é necessário instalar dependências adicionais para a execução básica.

5. Instalação e execução local

1. Acesse o repositório do projeto no GitHub.
2. Baixe os arquivos do projeto ou clone o repositório para o computador.
3. Abra a pasta do projeto no editor de código.
4. Localize a pasta "html".
5. Abra o arquivo "index.html" em um navegador.
6. Navegue pelas páginas e teste os formulários e as funcionalidades disponíveis.

Caso o projeto utilize caminhos relativos para imagens, folhas de estilo e scripts, mantenha a estrutura original das pastas para que os arquivos sejam carregados corretamente.

6. Dependências e build

O projeto utiliza tecnologias front-end executadas diretamente pelo navegador e não possui, na configuração atual, um processo específico de build ou um gerenciador de dependências como npm.

Por isso, não há um comando de build definido. Se forem adicionadas ferramentas de compilação ou empacotamento no futuro, as instruções correspondentes deverão ser documentadas nesta seção.

7. Testes e validação

A validação do projeto pode ser realizada por meio das seguintes verificações:

- Abrir as páginas no navegador e verificar se o conteúdo é exibido corretamente.
- Testar os links e a navegação entre as páginas.
- Preencher e testar os formulários.
- Conferir se imagens, estilos e scripts são carregados corretamente.
- Verificar a adaptação do layout em diferentes tamanhos de tela.
- Avaliar aspectos de acessibilidade, incluindo o uso de atributos ARIA e a navegação por teclado.
- Utilizar o validador HTML do W3C para identificar possíveis problemas de marcação.

Os testes devem ser realizados novamente sempre que houver alterações relevantes no código.

8. Versionamento e organização do trabalho

O projeto utiliza Git para registrar as alterações e GitHub para armazenar o repositório remoto.

Foram utilizadas as seguintes branches:

- "master": referência da versão estável do projeto.
- "develop": branch de integração do desenvolvimento.
- "feature/acessibilidade": desenvolvimento das melhorias de acessibilidade.
- "feature/melhoria-documentacao": criação e atualização da documentação.
- "hotfix/correcao": branch destinada a correções urgentes.

Os commits registram as alterações realizadas. A tag "v1.0.0" identifica uma versão do projeto. Também foram utilizadas uma Issue para registrar a tarefa de acessibilidade, uma Milestone para organizar as tarefas da versão e um Pull Request para propor a inclusão da documentação na branch "develop".

9. Objetivo acadêmico

O objetivo do projeto é aplicar os conhecimentos de desenvolvimento front-end, acessibilidade e controle de versão, praticando a organização dos arquivos e o uso do Git e GitHub durante o desenvolvimento de uma aplicação web.
