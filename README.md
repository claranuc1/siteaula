ONG Esperança

Sobre o projeto

Este projeto consiste no desenvolvimento de um site para a ONG Esperança, com o objetivo de apresentar a organização e facilitar o acesso às informações sobre seus projetos e formas de participação.

Funcionalidades

- Apresentação da ONG.
- Página de projetos sociais.
- Cadastro de usuários.
- Melhorias de acessibilidade na navegação e nas mensagens do cadastro.

Tecnologias utilizadas

- HTML
- CSS
- JavaScript

Objetivo

Aplicar os conhecimentos de desenvolvimento front-end e controle de versão utilizando Git e GitHub.
